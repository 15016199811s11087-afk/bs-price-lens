# BS Price Lens

[Open the website](https://15016199811s11087-afk.github.io/bs-price-lens/)

Made by **issac xiao**

**Design Thinking Project 2**

Public website files for the Battle Spirits catalogue, Hong Kong/Japan shop references and player exchanges. No online game or deck builder.

The catalogue snapshot contains 15,398 card numbers across 288 official Japanese product lists checked on 4 November 2026. Card artwork belongs to BANDAI and the respective rights holders. Retail prices/stock are source-specific observations and can change.

This repository contains only the files served by GitHub Pages. Independent price and exchange API: https://bs-price-lens-api.bs-e-system.workers.dev . The API address in config.json is public configuration, not a credential. Exchange management keys and private contact information are stored only by the application service and are never committed here.
